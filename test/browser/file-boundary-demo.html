THREECORE · LOCAL SECURITY CHECK

停止した読み込みを、保存内容へ戻さない

PC内の確認専用画面です。架空の小さなデータだけを使います。実ファイル・実Wallet・外部通信・送金を使用しません。

確認する項目を選んでください。

正常な入力

DAT・EMA・CAWELONの文字列を含む架空のJSONを読み込み、内容を照合します。

停止と遅い完了

読込みを保留して停止した後、遅れて返る結果が取り込まれないことを確認します。

同時読み込みの上限

4件が未完了なら5件目を受け付けません。停止後も元の処理が終わるまで枠を保持します。

確認の順序

  1. 「正常なJSONを確認」を押し、正常な読み込み結果を確認します。
  2. 「模擬読み込みを1件保留」を押し、未完了件数が増えたことを確認します。
  3. 保護欄の「進行中のファイル読み込みを止める」を押します。
  4. 「保留した模擬処理を完了」を押します。完了件数は増えず、未完了だけが減ります。

この確認は第三者によるセキュリティ監査ではありません。表示する入力サイズはブラウザー全体のメモリ使用量ではありません。

この画面の確認結果

固定した結果名と件数だけを表示します。ファイル名や入力内容は記録しません。
