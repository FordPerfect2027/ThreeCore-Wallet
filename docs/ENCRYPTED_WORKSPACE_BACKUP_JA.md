# 合言葉付きバックアップの使い方

PC内の開発版に、保存したファイルを合言葉で保護する機能を追加しました。
対象はDAT・EMA・CAWELONの設定、トークン一覧、保存済みの残高履歴です。
GitHubや本番サイトへの反映とは別の、ローカル開発版です。

## 保存する

1. 「3ウォレットをまとめて保存・復元」の中にある
   「合言葉付きでバックアップを守る」を開きます。
2. 長く、推測されにくい合言葉を2回入力します。
3. 合言葉を別の安全な場所で管理することを確認します。
4. 「暗号化ファイルを準備」を押します。
5. 準備完了後、「暗号化ファイルをダウンロード」を押します。
6. ブラウザーのダウンロード一覧で、PCに保存できたことを確認します。

ファイル名は `ThreeCore-workspace-encrypted.json` です。
同名のファイルを複数保存するときは、ブラウザーやOSの保存先で区別してください。
保存ボタンを押しただけでは、PCへの保存完了までは確認できません。

入力欄は処理開始時に消えます。合言葉そのものはバックアップに入りません。
合言葉を忘れた場合、こちらから元に戻す仕組みはありません。
ウォレットの秘密鍵・シードフレーズ・MetaMaskのパスワードは入力しないでください。

## 保存したファイルを開く

1. 「保存済みの暗号化ファイル」でファイルを1つ選びます。
2. 保存時の合言葉を入力し、「合言葉でファイルを開く」を押します。
3. 検証が完了したら、「復元用の入力欄へ渡す」を押します。
4. 「一括復元の変更内容を確認」を押し、変更内容を読みます。
5. 内容を確認したチェックを付けてから、一括復元を実行します。

ファイルを選んだだけでも、合言葉で開いただけでも、設定や履歴は変更されません。
既存の履歴を置き換える場合は、削除される内容の追加確認が必要です。
復元してもウォレットの接続許可や署名権限は復元されません。
必要なカードで改めて接続してください。

## 途中で止める

「合言葉・読み込み内容を消去」を押すと、入力欄と復元待ちの内容が消えます。
画面を隠したときや、ウォレットの保護停止を使ったときも同じように消去します。
入力中の合言葉や開いた内容は、操作がないまま約2分経過すると消去されます。
必要ならファイルを選び直して開いてください。

暗号処理の中断直後は、ブラウザー内部の処理が終わるまで少し待つ場合があります。
「前の暗号処理が終了するまで」と表示されたら、少し待ってからやり直してください。
自動的な再実行や、平文での代替保存は行いません。

## エラーが出たとき

| 表示 | 対応 |
| --- | --- |
| 2回の合言葉が一致しない | 同じ合言葉を入力し直します |
| 合言葉が違うかファイルが変更・破損 | 保存時の合言葉と元のファイルを確認します |
| 対応する形式ではない | 暗号化して保存したJSONを選びます |
| 設定または履歴が変わった | 現在の状態で最初から確認します |
| 一定時間が経過 | ファイルを選び直して開きます |
| ダウンロードを開始できない | ブラウザーの状態を確認して準備し直します |

## 保存範囲について

この暗号化ファイルに含まれるのは、3カードの一括バックアップ範囲です。
期間レポート、承認額、送金記録などの別コレクションを全部まとめる機能ではありません。
以前の平文ファイルやブラウザー内の保存内容も、自動では暗号化されません。
それぞれ必要な保存方法で保全してください。

開けたファイルであっても、中の残高履歴が現在の残高や本人の所有を証明するわけではありません。
ファイルの内容と復元先を確認してから反映してください。
今回の動作検証はPC内の開発検証であり、第三者のセキュリティ監査ではありません。
