# 提案と見積もりの画面照合・保存

2026年11月3日。公開dApp見積もりの[取得・照合処理](AERODROME_PROPOSAL_QUOTE_2026-11-03.md)に、
`/proposals/quote/` の画面と原本付き保存を追加した。提案画面から別タブで開ける。

## 使える経路

1. 提案照合で保存した記録と見積もりの2ファイルを選ぶ。または、この画面で保存した1ファイルを選ぶ。
2. 取得時刻とブロック時刻からの許容時間、受取額減少と許容変動の上限を明示して入力する。
3. 現在時刻で照合し、金額・対象・元ブロック・期限・上限の不一致を個別に表示する。
4. 元のファイルの文字列、条件、照合時刻と結果を1ファイルに保存する。
5. 読み戻すと保存時の結果を再計算する。現在時刻での再照合までは現在の一致表示・再保存を行わない。

金額は通常のトークン単位へ変換して表示する。割合入力は小数2桁までの文字列から整数へ変換し、
浮動小数点の丸めで上限が変わらない。ファイル切替・条件変更・取消・ページ離脱で古い処理を取り消す。
画面のCSPはネットワーク接続を禁止しており、公開RPCの取得は既存のCLIで行う。
この段階では取得画面、USDCを支出する予算、ガス見積もり、隔離実行との接続は未完。

## 検証した結果

- 新機能の保存・画面・全モジュール配信：13件成功。
- 提案機能とサーバー境界を含めた関連検証：48件成功。前者と重複しており合算しない。
- 通常のサーバー `127.0.0.1:4249` と実ブラウザーで条件一致、許容変動上限超過、期限切れを確認。
  これらの入力は試験用データで、実残高やAI生成の証拠ではない。
- 第4ケースは公開チェーンから取得済みのDAT見積もりと試験用提案をあえて組み合わせ、
  使用額・元ブロック不一致・取得時刻とブロック時刻の超過を確認した。
- 4個の実ダウンロードをディスク上で再計算し、保存された理由と結果の一致を確認。
  最初のダウンロードを画面から読み戻し、条件が復元され、現在結果がいったん消えることも確認した。
