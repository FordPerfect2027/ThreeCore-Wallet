# Bounded batch recomputation of explicitly listed rehearsal reports

Item 507. Source: `3e80f6e`.

An offline batch command now checks both exact saved bytes and report calculations for an explicit SHA-256 manifest. Up to 50 JSON reports are processed sequentially, with a 2 MiB per-report limit, 32 MiB cumulative admitted-byte limit and 256 KiB manifest limit. The existing portable manifest grammar rejects traversal, absolute/device paths and duplicate portable names. Only files below the real manifest directory are read. Outside junctions, self-reference, duplicate resolved paths/physical aliases, nonregular files and over-budget files are refused. Opened-handle metadata is compared before content is read; byte counts, metadata and path identity are checked after reading and after asynchronous review. A changing manifest suppresses the whole result. Individual source reads are observations, not an atomic filesystem snapshot.

Each report receives an exact digest and independent recomputation. Results distinguish agreement, changed derived results, checksum mismatch, unsupported report format and unreadable files while preserving earlier successful rows. A failed expectation inside a faithfully recomputed report stays explicitly counted; agreement does not authenticate origin, prove expected values, observe real balances or authorize execution. Source text is not echoed in the result. Owned immutable results can be saved as complete JSON or a formula-safe BOM/CRLF CSV viewing summary. Input files are never rewritten, repaired or restored.

Use `node scripts/verify-rehearsal-report-batch.js SHA256SUMS.txt [--format json|csv]` or `npm run rehearsal:verify-batch -- SHA256SUMS.txt`. Exit 0 means all listed checksums and recomputations agree, even if a faithful report explicitly describes failed expectations; inspect the separate failed-expectation count. Exit 2 retains per-file failure results. Exit 1 means invalid/changing manifest or arguments, with no partial result emitted. The manifest selects reports; the command does not scan directories or fetch anything.
