# Aerodrome見積もりの画面取得

2026年11月3日。`/quotes/` からDAT・EMA・CAWELONとnative USDCの見積もりを取得し、
既存の[提案・見積もり照合](PROPOSAL_QUOTE_UI_2026-11-03.md)に渡すファイルを保存できるようにした。
この画面はBase Mainnetの公開読み取りだけを使い、MetaMaskに接続しない。

## 操作と境界

- トークン、方向、入力額、最小受取額用の許容変動、任意のブロック番号を指定する。
- 入力額はDAT等で小数18桁、USDCで小数6桁まで。文字列から整数へ変換し浮動小数点を使わない。
- ブロック番号を指定すればその高さで取得し、空欄なら取得開始時の高さを固定する。
  以前のブロックを取り直してもブロック時刻は更新されない。
- Pool・Router・整数計算、Factory・トークンの組、canonical hashの再確認が揃って初めて結果を表示する。
- 条件変更、取消、ページ離脱で取得を取り消す。途中の値や、前の条件の結果を保存しない。
- 保存したファイルは従来のCLI検証と同じ形式で、原本付き提案との照合画面に読み込める。

HTTP側はローカルの正確なOrigin、POST、JSON形式を要求する。公開先やRPCメソッドを入力から
指定できず、2件を超える同時取得は拒否する。要求本文は1024バイト・5秒、上流取得は最大120秒、
クライアントは125秒に制限する。切断時は上流も中止する。署名・送信する経路は追加していない。

## 確認結果

保存・取消・入力変換・応答の対象照合、サーバー境界を含む関連検証56件が成功した。
最初の16件の実行と重複しているため合算しない。
通常サーバー `127.0.0.1:4250` の実ブラウザーから、次の同一ブロックの公開見積もりを取得・保存した。

| 入力 | 受取額 |
| --- | --- |
| 1,000 DAT | 0.009889 USDC |
| 1 USDC | 83,298.950016060663452663 EMA |
| 1 USDC | 41,853,288,417.310238740546419920 CAWELON |

対象はBase Mainnet **53,457,078**、hash
`0xe60495e68f89e6bf1dc9d70baadf368aa30027864b71dcbdf57b8c78f0ad656a`。
各見積もりはこの状態に対する独立した照会で、現在価格や連続した交換のシミュレーションではない。
ダウンロードされた3ファイルを再計算し、取得時刻を除く全項目が既存CLIの同一ブロック記録と
一致するか照合する。実行結果は[保存ファイル検証](evidence/2026-11-03-aerodrome-quote-ui/browser-download-verification.json)、
検証対象ソースとハッシュ一覧は同フォルダーに保存する。

## 残る実装

USDCを支出する提案の予算、ガス代・承認額を含む実行前検査、隔離環境での実行との接続は未完。
製品内AIの接続も、既に確認中の認証方法の選択を待っている。読み取りと照合の完成を全体90%とは扱わない。
これらの変更は既存の固定ZIPには含まれず、次の統合版の対象となる。
