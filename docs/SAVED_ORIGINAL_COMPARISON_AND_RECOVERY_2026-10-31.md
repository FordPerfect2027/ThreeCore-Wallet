## Offline reproduction

The commands below read local JSON and write their result to stdout. They do not modify inputs or contact a network.

`node scripts/compare-wallet-saved-files.js before.json after.json --json`: 0 means the same validated original, 2 means different/unverified, 1 means invalid.

`node scripts/verify-wallet-saved-comparison.js before.json after.json comparison.json --json`: 0 means faithfully reproduced, 2 means mismatch, 1 means invalid.

`node scripts/wallet-saved-bundle.js create before.json after.json`: emits both complete plaintext originals and the comparison. `check bundle.json --json` produces a metadata-only review. `extract bundle.json before` or `after` emits exactly that original only after a faithful review. Check/extract return 2 on mismatch; extraction then emits no source bytes. Invalid input returns 1 without partial output.
