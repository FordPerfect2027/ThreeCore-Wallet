# Avoid hashing the same captured batch source twice

Item 529. Source: `22435d1`.

Both text and selected-file batch inspection already compute the exact source SHA-256 before checking the original. The original inspector previously computed the same full-text hash again. The batch now reuses its locally captured digest through a private helper, after retaining every existing schema/content/internal-checksum check. The input is an immutable captured string, and public options, extra arguments and imported inspection receipts cannot inject the reused hash. External checksum mismatch still stops before original validation. Cancellation and timeout checkpoints remain in place. Standalone inspections still compute their own exact hash.
